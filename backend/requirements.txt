#   only stops it changing by itself tomorrow. Verified on BOTH interpreters in one run (CI run
#   31103393912): ci.yml's 3.11 and render.yaml's declared 3.12 resolve all seven IDENTICALLY, so
#   these pins are interpreter-independent and both installs succeeded.
