# commit, no review and no CI signal, in the subsystem this repo calls a regression graveyard.

# resolving to **2026.7.0** — two and a half years past the declared minimum, and it moved again
# between two installs hours apart (2026.4.0 -> 2026.7.0).
#

#   only stops it changing by itself tomorrow. Verified on BOTH interpreters in one run (CI run
#   31103393912): 3.11 and 3.12 resolve all seven IDENTICALLY and both installs succeeded, so these
#   pins are interpreter-independent — which is why they were safe to ship even before production's
#   interpreter was known.

#   MEASURED rather than read off render.yaml — the Blueprint could not be trusted on its own,
#   because this service may not be Blueprint-synced. ci.yml moves to 3.12 in this same change, so
#   the test lane finally installs the stack the server runs.
