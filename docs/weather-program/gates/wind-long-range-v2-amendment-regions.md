# Amendment R1 to gate wind-long-range-v2: ALASKA and CARIBBEAN_PR become fixed gated regions
Date: 2026-11-23, written BEFORE 2026-12-01 and before any FIT or TEST score, fit coefficient, forecast value or truth row of this gate has been read or computed. Made by the wind-long-range lane on David's ruling "Add + Europe insurance" (2026-11-23, relayed by the director, `local_d6b521eb`). The registration (`wind-long-range-v2.md`, gate PASS at 8ea5fd219) and amendments 1, 2, G1 and L1 are not edited; this file records what changes and how the registration is read from now on. To be sent to the advisor BEFORE the first TEST init.

## R1.1 Why (the disclosure, stated first)
The registration expects three gated regions with at least 10 marine-exposed stations each (US Pacific, US Atlantic + Gulf, Hawaii). The frozen list (PR #1240, run 45253166505) shows that Hawaii has only 11 stations (8 NDBC, 3 ASOS) before the marine-exposed rule, the LOCKED drop and score-time coverage, so the wind floor would be VOID unless every Hawaii station survived, and the gust floor (NDBC only) is VOID by construction. The same list holds 130 US stations that the five registered regions leave in `OTHER`: 120 in Alaska and the northern Pacific, 10 in the Caribbean and Puerto Rico. **The two regions are added because of these station counts, after the counts were seen.** Nothing else informed the choice: no score, fit, forecast value or observation row was read. Alaska is a distinct wind regime (high-latitude North Pacific, Gulf of Alaska), not a re-labelling of an existing region.

## R1.2 What changes
| # | Rule |
|---|---|
| R1 | `ALASKA` = `lat > 50.0` and `lon <= -125.0` (longitude normalised to -180..180, so the Aleutians west of the dateline are included). The latitude 50.0 exactly belongs to `US_PACIFIC`, which is tested first. |
| R2 | `CARIBBEAN_PR` = `10.0 <= lat < 24.0` and `-90.0 <= lon <= -58.0`. Florida and the Keys (24 N and north) stay `US_ATLANTIC_GULF`; the Gulf of Mexico west of 90 W stays `OTHER`; Hawaii is unchanged. |
| R3 | Both are FIXED gated regions, not optional: they enter F6 and G6/GG6 (Holm within each arm x bin across regions) and the floor counts exactly like the five registered regions. The regions list becomes the five plus these two. `GREAT_LAKES` stays EXCLUDED; `BLACK_SEA` and `OTHER` stay reported-only. |
| R4 | The calibration fit is per (bin x region) as registered: a new region gets its own cell when it has >= 100 station-days, otherwise it borrows the bin's pooled fit (flagged), the registered rule. Nothing about the fit changes. |
| R5 | **No floor changes.** >= 10 marine-exposed stations with >= 70% hourly records in each of >= 3 regions, for wind; the same per-region 10 and 3-region rule for gust (G1 section G5, ADJUSTED NDBC GST stations only; ASOS never counts for gust). A region below its minimum is "insufficient", never a verdict. Fewer than 3 sufficient regions VOIDS the wind verdict, or the gust verdict, exactly as registered. |

## R1.4 Safeguards (no rescue clauses)
- The definitions in R1 and R2 are fixed by this file and by `wind_lr2_runs.region_of`, whose assignment is reproduced from the committed list by `tests/test_wind_lr2_regions.py` (partition, counts and the list hash).
- After the first TEST init: no relaxing of any floor, no redrawing of any region boundary, no adding of stations, regions or sources. A change made after TEST starts is not part of this test.
- Eligibility is the frozen rules only (catalogue rules at freeze, marine-exposed rule, pairing, LOCKED drop, score-time coverage). No station is added or removed by skill.
- Risks, stated so a pass cannot hide them: many Alaska stations are fjord, sea-ice or seasonal C-MAN stations, so the marine-exposed rule and winter coverage at SCORE time may still leave `ALASKA` below 10; `CARIBBEAN_PR` has exactly 10 NDBC stations, so it is sufficient only if all 10 survive. If fewer than 3 regions are sufficient the verdict is VOID as registered. The gust floor is the tighter of the two (NDBC only, ADJUSTED heights).

## R1.5 What this does not do
It adds no data source, changes no arm, bar, family, control, truth rule or coefficient rule, and moves no served number. A European source is NOT added here: that is a separate dated amendment (R2) written only if a source verifies, before 2026-12-01, with its provenance, QC and gap rules frozen; if it does not verify by then it does not enter this test. TEST does not start until this amendment is merged.
