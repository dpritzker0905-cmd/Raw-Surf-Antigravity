## 8. Tooling facts learned tonight
- **The gh token gates `git push` too** (§1.3). Public run metadata reads without a token
  (`api.github.com/repos/<owner>/<repo>/actions/runs/<id>` and its `/jobs`), but job LOGS answer HTTP 403 without one,
  so a hosted floor reading needs `gh run view <run> --log --job <id>`.
- **`action_ledger.py append` refused an estimated time** in `verified` ("01:3xZ"): give a bound between two clock
  reads instead. The L-P10 check works.
- **A guard needs its own mutation check** (L-P20): the first, line-order version of the diagnostics guard stayed green
  when step 4's copy was reverted, because the fallback's copy ~180 lines up "covered" it.
- **A machine reset mid-mutation leaves the mutant in the tree.** After a reset, `git status` and `git diff` before
  anything else; here the step-4 mutant was found applied, finished as a measurement, and restored from the commit.
- Some modules under `routes/` carry a UTF-8 BOM (`routes/bookings/crew_hub.py` and others): read source with
  `encoding="utf-8-sig"` before `ast.parse`.
